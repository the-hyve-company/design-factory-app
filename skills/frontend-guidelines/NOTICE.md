## What this skill is (and is not)

Because the upstream text is not licensed for reuse, this skill does **not**
copy it. It is an original piece of writing that covers the same _practices_
(semantic HTML, brevity, accessibility, performance, low-specificity CSS,
transform-only animation, stateless/functional JS):

- every rule is re-stated in original wording;
- every `bad/good` pair uses original examples — none of the upstream code
  snippets are reproduced;
- the rule ordering and grouping follow the topic areas, which are ideas,
  not protected expression.

Attribution to the upstream repository is given as a courtesy and to point
readers at the original work — it is not a claim that this text is licensed
by it.
